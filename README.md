# LM Studio Chat

一个简单的HTML聊天界面，用于与本地LM Studio进行对话。

## 功能特性

- 多轮对话 - 支持上下文记忆
- 流式响应 - 实时显示AI生成文字
- 美观界面 - 类似ChatGPT的对话样式
- 本地存储 - 对话历史保存在浏览器
- 响应式设计 - 支持手机、平板和电脑访问

## 使用方法

### 方法一：直接打开HTML文件（仅本机可用）

1. 双击 `lmstudio-chat.html` 文件
2. 在浏览器中打开
3. 开始对话

### 方法二：通过HTTP服务器共享到网络（推荐）

1. 确保已安装Python
2. 打开命令行终端
3. 运行以下命令：

```bash
python start-chat-server.py
```

4. 服务器启动后，会显示访问地址
5. 其他设备通过浏览器访问显示的"网络访问"地址

## 配置说明

### LM Studio API地址

默认API地址：`http://192.168.10.8:1234`

如果需要修改：
1. 点击右上角"设置"按钮
2. 修改"API地址"字段
3. 点击"保存"

### 模型选择

如果需要指定特定模型：
1. 点击右上角"设置"按钮
2. 在"模型"字段输入模型名称
3. 点击"保存"

## 文件说明

- `lmstudio-chat.html` - 主聊天界面文件
- `start-chat-server.py` - Python HTTP服务器脚本
- `README.md` - 本说明文件

## 注意事项

1. 确保LM Studio已启动并开放API服务
2. 确保本地网络设备可以访问LM Studio的API地址
3. 如果使用方法二，确保防火墙允许8765端口访问
4. 对话历史保存在浏览器本地存储中
